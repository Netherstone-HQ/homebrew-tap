# Netherstone for Homebrew

Install [Netherstone](https://netherstone.app) on macOS:

    brew install --cask netherstone-hq/tap/netherstone

Netherstone updates itself. This tap is updated with every release.

Netherstone isn't notarized by Apple yet, so macOS may refuse to open it the first time. Open it from System Settings > Privacy & Security > Open Anyway.

Problems with the app on: [Netherstone's issues](https://github.com/Netherstone-HQ/Netherstone/issues).
